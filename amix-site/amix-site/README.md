# Сайт Amix для ЮKassa и RuStore

1. Откройте файлы в Блокноте и замените всё в квадратных скобках `[...]` вашими данными (они подсвечены оранжевым).
   Ничего не выдумывайте: ЮKassa и RuStore сверяют эти данные с анкетой.
2. Опубликуйте на GitHub Pages: новый **публичный** репозиторий → загрузите все файлы из этой папки в корень →
   Settings → Pages → Branch `main`, папка `/ (root)` → Save. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
3. Этот адрес укажите в анкете ЮKassa как сайт. Страница `paid.html` нужна как `YOOKASSA_RETURN_URL`
   (`https://.../paid.html`).
