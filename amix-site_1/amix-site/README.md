# Сайт Amix (для RuStore и справки)

1. Замените всё в квадратных скобках `[...]` вашими данными (подсвечено оранжевым). Ничего не выдумывайте.
2. Опубликуйте на GitHub Pages: новый публичный репозиторий, файлы в корень, Settings → Pages → `main` / `(root)`.
3. Адрес страницы `policy.html` указывается в карточке приложения в RuStore как ссылка на политику конфиденциальности.
